# Interactive Webpage Project

## Overview
This project demonstrates basic JavaScript concepts including event listeners, form validation, and interactive elements. The webpage contains a simple form that collects user input and provides real-time feedback.

## Features
- **Event Listeners:** Captures form submission events for processing.
- **Form Validation:** Ensures that the user inputs are not empty and that the email format is valid.
- **Interactive Elements:** Displays error messages and success notifications based on user input.

## Technologies Used
- HTML
- CSS
- JavaScript
